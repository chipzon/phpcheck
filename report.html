chipzon/phpcheck

Verify a server is actually patched against php2shell (CVE-2026-109618 / 109619) — including the distro-backport case a version number can't show. You run the check on your own server; nothing you paste here leaves your browser.

Step 1 · on your server

Run the check

Download it, read it (it's ~90 lines), then run it. It sends no exploit and contacts no remote host — it reads php -v and the installed package's changelog.

curl -O https://raw.githubusercontent.com/chipzon/phpcheck/main/phpcheck.sh bash phpcheck.sh --json

Step 2 · here

Paste the JSON output

Paste what the command printed. You get a clean report you can screenshot or send to a client.

Open source · chipzon/phpcheck · self-check only, by design — it never scans other people's servers.
